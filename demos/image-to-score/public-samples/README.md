# Public image samples

These test images were downloaded from Wikimedia Commons for OMR integration tests:

- `twinkle-twinkle-cc0.png` — [Twinkle Twinkle Sheet Music](https://commons.wikimedia.org/wiki/File:Twinkle_Twinkle_Sheet_Music.png), released under CC0.
- `chester-billings-public-domain.png` — [Chester Billings Score](https://commons.wikimedia.org/wiki/File:Chester_Billings_Score.PNG), public domain.

They are kept as small, openly licensed fixtures for local testing. Generated OMR output belongs in a temporary output directory and is not committed by default.
